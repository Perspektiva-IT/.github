# Perspektiva IT

This is the official GitHub organization of Perspektiva IT.

## Om os

[Perspektiva IT](https://www.perspektiva-it.dk) blev grundlagt i 1992 med en vision om at tilbyde en bred vifte af IT-tjenester med fokus på kvalitet, innovation og kundetilfredshed. Vi er i dag +20 ansatte i en solid virksomhed.

## Vores værdier

Vi tror på, at succes bygger på mere end bare hårdt arbejde. Succes kræver et solidt fundament af kerneværdier, som hver eneste af os lever og ånder for.

### 🤝 Ansvarlighed
Vi tager ansvar for vores handlinger, løsninger og de resultater, vi skaber. Vi forpligter os til at levere kvalitet i alt, hvad vi gør, og anerkender vores rolle i teamets og kundernes succes.

### 🙏 Respekt
Vi behandler alle med respekt og værdighed. Vi lytter for at forstå og værdsætter forskelligheder som en styrke, der beriger vores arbejdsplads og de løsninger, vi udvikler.

### 🎯 Kundefokus
Vores kunder står i centrum for alt, hvad vi gør. Vi stræber efter at forstå deres behov dybt og tilbyde løsninger og service, der ikke bare opfylder, men overgår deres forventninger.

### 🔒 Troværdighed
Vi bygger relationer baseret på tillid. Ærlighed, gennemsigtighed og integritet — både internt og eksternt.

### 💡 Vidensbegær
Vi er drevet af en konstant trang til at lære og vokse. Vi omfavner innovation og søger konstant efter nye måder at forbedre os selv og de løsninger, vi leverer.
